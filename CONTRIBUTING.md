# Contributing to awesome-cyber-arsenal

Thanks for your interest in contributing! This guide will help you add resources to the list.

## How to Submit

### Option 1: Pull Request (Preferred)

1. Fork this repository
2. Create a new branch: `git checkout -b add/tool-name`
3. Add your resource to the appropriate section in `README.md`
4. Follow the format below
5. Submit a PR using the provided template

### Option 2: Issue

Open an issue with the **Resource Suggestion** template and fill in the details.

## Resource Format

Add entries in alphabetical order within their section:

```markdown
| [Tool Name](https://homepage.url/) | Short description (max 120 chars) | 🟢/🟡/🔴 | [GitHub](https://github.com/org/repo) |
```

## Maturity Badges

| Badge | Criteria |
|-------|----------|
| 🟢 Production-ready | Stable release, active maintenance, used in production |
| 🟡 Beta | Active development, usable but may have breaking changes |
| 🔴 Alpha | Experimental, proof of concept, early stage |

## Quality Standards

Before submitting, ensure the resource:

- [ ] Is related to cybersecurity (offensive, defensive, CTI, or DevSecOps)
- [ ] Has a working link
- [ ] Is actively maintained (commit in the last 12 months for GitHub projects)
- [ ] Has documentation or a README
- [ ] Is not a duplicate of an existing entry
- [ ] Description is concise (under 120 characters)

## What We Don't Accept

- Paid-only tools without a free tier or community edition
- Abandoned projects (no commits in 12+ months)
- Resources that promote illegal activity without educational context
- Self-promotion without genuine community value
- Tools that only work on a single proprietary platform with no open alternative

## Code of Conduct

Be respectful. This is a community-driven project. Constructive feedback is welcome; hostility is not.
